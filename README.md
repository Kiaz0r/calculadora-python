# Calculadora em Python

![Version](https://img.shields.io/badge/version-1.0.0--rc.1-orange.svg) ![Python](https://img.shields.io/badge/python-3.7+-3776AB.svg) ![License](https://img.shields.io/badge/license-MIT-brightgreen.svg)

Este projeto foi desenvolvido como uma porta de entrada para o mundo da programação em Python. O que começou como um simples estudo da linguagem, se transformou em uma calculadora funcional e com uma interface amigável.

## 🎯 Objetivo

O principal objetivo deste projeto foi aplicar e consolidar os conhecimentos básicos em Python, explorando a criação de interfaces gráficas e a lógica por trás de uma calculadora.

## ✨ Funcionalidades

O projeto oferece uma calculadora com as seguintes funcionalidades:

- **Operações matemáticas:** Adição, subtração, multiplicação, divisão, porcentagem, raiz quadrada e exponenciação ao quadrado.
- **Funções de conveniência:** Cálculo de recíproco e inversão de sinal do número atual.
- **Edição de entrada:** Permite apagar o último dígito ou limpar a entrada numérica atual.
- **Interface Gráfica:** Construída com CustomTkinter para uma aparência moderna e agradável.

## 🚀 Teste você mesmo

Para executar o projeto, siga os passos abaixo:

1. **Clone o repositório:**
   ```bash
   git clone https://github.com/Kiaz0r/python-calculator.git
   ```

2. **Crie um ambiente virtual:**
   ```bash
   python -m venv venv
   ```

3. **Ative o ambiente virtual:**
   - No Windows:
     ```bash
     .\venv\Scripts\activate
     ```

     - No macOS/Linux:
       ```bash
       source venv/bin/activate
       ```

 4. **Instale as dependências:**
    ```bash
    pip install -r requirements.txt
    ```

 5. **Execute a aplicação:**
    ```bash
    python app.py
    ```
